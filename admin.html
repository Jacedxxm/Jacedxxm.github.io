Admin — Portfolio Content

Edit the site's content here, then click "Download JSON" to get an updated data.json file. Upload that file to the same folder as index.html on your hosting (overwriting the old one, if present) and the site updates automatically. No content is sent online from this page: everything stays in your browser until you download the file.

Typography

Fonts used across the whole site, loaded live from Google Fonts. Pick from the curated list, or choose "Custom…" and type the exact name of any Google Font.

Font names are case-sensitive and must match Google Fonts exactly (check fonts.google.com). If a font fails to load, the site falls back to the browser's default sans-serif/monospace.
